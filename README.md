# script-migrate-to-haproxy
A python script to use with PagoPA templated repositories to open automatically PRs with the microservice chart update to [8.8.2](https://github.com/pagopa/aks-microservice-chart-blueprint/blob/microservice-chart-8.8.2/README.md) and the haproxy ingress migration

Needed:
- GITHUB_TOKEN env
- python3
- ruamel.yaml
`pip install PyGithub ruamel.yaml`
